01 Introduction

```

La présente Politique de Confidentialité explique quelles données peuvent être collectées et traitées lors de l'utilisation d'Inari (ci-après « le Bot »), un bot Discord développé pour proposer différentes fonctionnalités de gestion, de modération et d'interaction sur les serveurs Discord.

En utilisant ou en ajoutant Inari à un serveur Discord, vous reconnaissez avoir pris connaissance de cette Politique de Confidentialité.

```

02 Données collectées

```

Pour assurer le fonctionnement de ses fonctionnalités, Inari peut traiter certaines informations accessibles via l'API de Discord et nécessaires à son fonctionnement.

Identifiants Discord

  • ID des utilisateurs Discord
  • ID des serveurs Discord
  • ID des salons, rôles et messages nécessaires au fonctionnement des fonctionnalités configurées

Messages et interactions

  • Contenu de certains messages traités par les fonctionnalités du Bot
  • Commandes et interactions envoyées à Inari
  • Mentions utilisées dans les messages lorsque les systèmes anti-spam sont actifs
  • Informations nécessaires au traitement des commandes et actions de modération

Médias

  • Images et vidéos publiées dans les salons où le système de logs médias est configuré
  • Informations associées au message contenant le média, telles que l'auteur, le salon et la date d'envoi
  • Liens permettant d'accéder aux médias concernés
```

03 Confessions anonymes

```

La fonctionnalité de confessions permet aux utilisateurs d'envoyer un message présenté publiquement comme anonyme.

Important : une confession est anonyme pour les autres membres du serveur, mais son auteur est techniquement enregistré par Inari afin de permettre la gestion de la fonctionnalité et, lorsque les conditions prévues sont réunies, une éventuelle révélation à des administrateurs.

Pour chaque confession, Inari peut conserver :

  • L'ID Discord de l'auteur
  • Le contenu de la confession
  • L'ID du message public créé pour la confession
  • La date et l'heure de création
  • Le numéro attribué à la confession
  • Le statut de révélation de l'auteur
  • L'ID des administrateurs impliqués dans une éventuelle demande ou confirmation de révélation
  • La date et l'heure d'une éventuelle révélation

Les informations permettant d'identifier l'auteur d'une confession ne sont pas publiées automatiquement avec la confession.

```

04 Fonctionnalité Guess Number

```

Le jeu « Guess Number » enregistre certaines informations nécessaires au fonctionnement et aux statistiques de la partie.

  • L'ID Discord des utilisateurs ayant proposé un nombre
  • Les nombres proposés
  • Le nombre d'essais effectués
  • L'intervalle utilisé pour la partie
  • Les données nécessaires au suivi de la partie en cours

Ces données sont utilisées uniquement pour gérer la partie et afficher les statistiques correspondantes.

```

05 Configuration des serveurs

```

Lorsqu'un administrateur configure Inari sur un serveur, le Bot peut enregistrer les paramètres nécessaires à son fonctionnement.

Ces paramètres peuvent notamment comprendre :

  • Les IDs des rôles utilisés par les différentes fonctionnalités
  • Les IDs des salons utilisés pour les logs, le Jail, les jeux ou les confessions
  • Les paramètres des systèmes anti-spam
  • Les cooldowns et horaires des pings
  • Les paramètres des rôles automatiques
  • Les paramètres du système de confessions
  • Les paramètres du jeu Guess Number

Ces informations servent uniquement à conserver la configuration choisie par les administrateurs des serveurs.

```

06 Logs et modération

```

Lorsque les fonctionnalités correspondantes sont activées par un administrateur, Inari peut générer des journaux concernant certaines actions effectuées sur le serveur.

  • Détection de spam ou de mentions excessives
  • Détection d'activité sur plusieurs salons
  • Attribution ou retrait de rôles
  • Utilisation de certaines commandes administratives
  • Utilisation de la fonctionnalité « Inari Dit »
  • Publications contenant des images ou vidéos lorsque les logs médias sont configurés

Les logs peuvent contenir des identifiants Discord, des informations sur le salon concerné, le contenu d'un message et l'heure de l'action, selon la fonctionnalité utilisée.

```

07 Utilisation des données

```

Les données traitées par Inari sont utilisées uniquement dans le cadre du fonctionnement du Bot et de ses fonctionnalités.

Elles peuvent notamment être utilisées afin de :

  • Fournir les fonctionnalités demandées par les administrateurs et utilisateurs
  • Appliquer les systèmes de protection et d'anti-spam
  • Gérer les rôles et permissions configurés
  • Conserver les paramètres des serveurs
  • Gérer les confessions anonymes
  • Gérer les parties et statistiques du Guess Number
  • Créer des journaux de modération et de sécurité
  • Diagnostiquer et corriger les problèmes techniques du Bot
```

08 Stockage et conservation

```

Les données nécessaires au fonctionnement d'Inari peuvent être stockées dans les fichiers de données utilisés par le Bot, notamment pour conserver les configurations des serveurs, les cooldowns, les confessions et les parties de Guess Number.

La durée de conservation peut varier selon le type de donnée et sa nécessité pour le fonctionnement du Bot.

Nous ne conservons pas volontairement les données plus longtemps que nécessaire au fonctionnement des fonctionnalités concernées, sous réserve des contraintes techniques et des obligations applicables.

```

09 Partage des données

```

Les données traitées par Inari ne sont pas vendues à des fins commerciales.

Certaines informations peuvent toutefois être visibles par les personnes disposant des permissions nécessaires sur un serveur Discord, notamment lorsque les administrateurs ont configuré des salons de logs.

Inari fonctionne également sur l'infrastructure de services tiers nécessaires à son hébergement et à son fonctionnement. Les données peuvent donc transiter par ces services conformément à leur propre politique de confidentialité.

```

10 Discord

```

Inari fonctionne sur la plateforme Discord et utilise les services et API fournis par Discord.

Discord peut collecter et traiter ses propres données conformément à ses propres politiques et conditions.

Pour plus d'informations, consultez la Politique de Confidentialité de Discord .

```

11 Sécurité

```

Nous mettons en œuvre des mesures raisonnables destinées à protéger les données traitées par Inari contre les accès non autorisés, la perte ou la modification.

Toutefois, aucun système informatique ou service en ligne ne peut garantir une sécurité absolue.

```

12 Droits des utilisateurs

```

Selon la législation applicable, notamment lorsque le RGPD est applicable, vous pouvez disposer de certains droits concernant vos données personnelles.

Vous pouvez notamment demander :

  • L'accès aux données personnelles vous concernant
  • La rectification de données inexactes
  • La suppression de certaines données
  • La limitation de certains traitements
  • Des informations concernant l'utilisation de vos données

Pour exercer une demande concernant les données traitées par Inari, contactez-nous via notre serveur de support Discord.

```

13 Suppression des données

```

Vous pouvez demander la suppression des données personnelles associées à votre utilisation d'Inari lorsque leur conservation n'est plus nécessaire ou lorsqu'aucune obligation légale ou nécessité technique ne justifie leur conservation.

Les demandes peuvent être examinées au cas par cas afin de vérifier qu'elles concernent bien les données traitées par Inari.

Demande de suppression :

Contactez-nous via le serveur de support Discord indiqué dans la section « Contact ».

```
